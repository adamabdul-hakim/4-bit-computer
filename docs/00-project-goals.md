# Project Goals and Success Criteria

## 4-Bit Computer Project

### Purpose

Our goal is to build a simple programmable 4-bit computer from first principles so that we can understand how a computer executes instructions at the hardware level.

The focus of this project is not performance or complexity. We want to understand how components such as logic gates, registers, buses, memory, the ALU, and the control unit work together to execute a program.

### Primary Goal

Build a working 4-bit computer that can:

- Store and execute a small program
- Perform basic arithmetic and logic operations
- Move data between registers and memory
- Support simple control-flow instructions
- Produce visible output
- Be manually stepped through so we can observe execution

### Success Criteria

We will consider the project successful when:

- The 4-bit computer reliably executes at least two small programs
- We can trace an instruction through fetch, decode, and execute
- Both team members can explain every major subsystem
- We understand how machine-code instructions become control signals and electrical behavior
- The architecture, design decisions, debugging process, and final system are documented

### Design Principles

- Understanding is more important than complexity
- Build and test small components before integrating them
- Derive and understand circuits instead of blindly copying them
- Document failures and debugging, not just successful results
- Divide the work, but make sure both team members understand the entire system
- Keep the design modular enough that it could potentially be extended to 8 bits later

### 8-Bit Extension

An 8-bit computer is a stretch goal, not a requirement.

If time permits after completing the 4-bit computer, we will evaluate how the architecture can be extended to 8 bits and identify which components can be scaled directly and which would require redesign.

The 4-bit computer itself is the primary deliverable.
